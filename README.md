## 🧩 About The Project

**HTML Forms** is a simple and practical web form project created using
**HTML5** to demonstrate how different form elements and attributes
are used to collect information from users.

The project focuses on understanding the structure of HTML forms and
the practical use of different input controls.

> 🎯 **Goal:** Strengthen HTML fundamentals by building a complete and
> user-friendly form using different HTML form elements.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 👤 **Personal Information** | Collects basic user details |
| 📧 **Email Field** | Accepts email address |
| 📱 **Phone Number** | Collects contact information |
| 🎓 **Education Details** | Allows users to provide education information |
| 💻 **Skills Selection** | Select relevant technical skills |
| 🔘 **Radio Buttons** | Select one option from multiple choices |
| ☑️ **Checkboxes** | Select multiple options |
| 📋 **Dropdown Menu** | Select from predefined options |
| 📝 **Text Area** | Enter detailed information |
| 🚀 **Submit Button** | Submits the form |
| 🔄 **Reset Button** | Clears entered information |
