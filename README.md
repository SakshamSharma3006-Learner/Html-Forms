## 🧩 About The Project

**HTML Forms** is a simple and practical web form project created using
**HTML5** to demonstrate the use of different form elements, input
types and attributes.

The project represents a **student hiring form** designed for a company
to collect important information such as personal details, education,
skills and other requirements from students.

> 🎯 **Goal:** Build a practical HTML form while strengthening
> fundamental concepts of HTML forms and user input handling.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 👤 **Personal Details** | Collects student's basic information |
| 📧 **Email Input** | Accepts the student's email address |
| 📱 **Phone Input** | Collects contact information |
| 🎓 **Education Details** | Collects academic information |
| 💻 **Skills Selection** | Allows students to select their skills |
| 🔘 **Radio Buttons** | Allows selection of a single option |
| ☑️ **Checkboxes** | Allows selection of multiple skills/options |
| 📋 **Dropdown Menu** | Provides predefined choices |
| 📝 **Text Area** | Allows detailed information |
| 📎 **File Input** | Allows document/resume selection |
| 🚀 **Submit Button** | Submits the entered information |
| 🔄 **Reset Button** | Clears the form fields |
